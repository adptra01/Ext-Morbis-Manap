Ringkasan singkat

Ekstensi ini adalah alat bantu kerja untuk SIMRS MORBIS di lingkungan rumah sakit. Data Anda tidak dijual, tidak dipakai untuk iklan, dan tidak dikirim ke pihak ketiga mana pun. Semua pengiriman data hanya terjadi antara komputer Anda dan server milik rumah sakit sendiri (server MORBIS dan server Reports RS).

1. Data yang hanya tersimpan di komputer Anda

  • Pengaturan ekstensi (fitur aktif/nonaktif, peran/role, daftar alamat server).
  • Penanda dan riwayat lokal (mis. pasien pre-op, riwayat simpan resume) sebagai cadangan bila server tidak terjangkau.

Data ini tidak pernah keluar dari komputer Anda kecuali untuk sinkronisasi ke server rumah sakit seperti dijelaskan di bawah. Menghapus ekstensi akan menghapus data lokal ini.

2. Data yang dikirim ke server rumah sakit

Agar data sama di semua komputer (antar-PC), ekstensi mengirim hal berikut ke server milik rumah sakit (dev.rsudkotajambi.id dan server aplikasi MORBIS):

  • Nomor antrean farmasi/loket — agar layar antrean dan pemanggil sinkron.
  • Penanda pre-op, revisi klaim BPJS, dan riwayat simpan resume — beserta nama petugas dan waktu simpan, agar riwayat yang sama terlihat di PC/akun lain.
  • Teks panggilan suara (mis. nomor antrean + nama pasien) — hanya bila suara di komputer gagal dan fitur "Suara Server Cadangan" aktif. Server mengubah teks menjadi suara dan mengembalikannya; salinan suara disimpan sementara (±12 jam) agar panggilan ulang tidak perlu diproses lagi.

3. Pihak ketiga

Tidak ada. Ekstensi tidak menghubungi, mengirim data ke, atau memakai layanan milik pihak ketiga mana pun (termasuk layanan analitik, iklan, Telegram, Cloudflare, maupun Google). Proses suara yang dulu memakai layanan luar kini dikerjakan oleh server rumah sakit sendiri.

4. Kontrol Anda

  • Setiap fitur dapat dimatikan lewat popup ekstensi (ikon extension → daftar Fitur).
  • "Suara Server Cadangan" dapat dimatikan — suara tetap bunyi dari komputer sendiri selama fasilitas suara lokal tersedia.
  • Menonaktifkan/menghapus ekstensi menghentikan semua pengiriman data.

5. Keamanan

Komunikasi berjalan di jaringan internal rumah sakit. Ekstensi tidak menyimpan kata sandi dan tidak menanamkan kredensial apa pun di dalam paket.

6. Perubahan kebijakan
