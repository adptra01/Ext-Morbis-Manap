Instalasi
Tiga langkah sederhana
Pilih metode yang paling cocok — manual download atau auto install untuk enterprise.

Method 1: Download ZIP

1

Download dari GitHub

Buka halaman main branch, klik Code lalu Download ZIP.

2

Extract & Load

Extract ZIP, buka edge://extensions/, aktifkan Developer mode, klik Load unpacked lalu pilih folder hasil extract.

3

Selesai

Ekstensi langsung aktif. Icon MORBIS muncul di toolbar browser.

Method 2: Auto Install (.reg)

1

Download File .reg

Buka halaman deploy, download Install_Morbis_Ext.reg.

2

Double-Click

jalankan file .reg, klik Yes lalu OK pada dialog Windows.

3

Restart Browser

Tutup semua jendela browser, buka kembali — ekstensi otomatis terinstal.

Branching strategy

Branch Isi Tujuan
dev Source code lengkap (src/, scripts/, tests/) Pengembangan
main File ekstensi di root (manifest.json, background.js, dll) Distribusi / Edge Add-ons

Push ke dev otomatis build dan deploy isi ke main via GitHub Actions. File ekstensi ada di root — download langsung siap pakai.
